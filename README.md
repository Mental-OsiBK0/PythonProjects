# PythonProjects

A collection of Python projects I've written over the years.

## CyberSecurity

Network security tools I wrote while learning ethical hacking.
All of them were tested only in my own lab environment, for educational purposes.

- **NetScanner**: scans devices on the local network
- **MyPacketListener**: captures and reads network packets
- **MacChanger**: changes the MAC address of a network interface
- **MITM**: ARP spoofing / man-in-the-middle with Scapy
- **Socket**: simple client-server messaging

## FreelanceWorks

Small desktop tools I built for real businesses, such as cost/scrap calculation for a steel factory and VAT withholding calculation for a steel trading company.
